▸ How to use: translate Mac (Apple Silicon) · PC (NVIDIA CUDA)

Mac (Apple Silicon): mlx-whisper + local llama.cpp

  1. Install tools: 
    brew install node ffmpeg llama.cpp
  2. Create the whisper venv: 
    python3 -m venv ~/mlx-whisper-env
~/mlx-whisper-env/bin/pip install -U mlx-whisper silero-vad
  3. Get anime-whisper in MLX format (one time), with the venv's python and mlx-examples' whisper/convert.py: 
    python convert.py --torch-name-or-path litagin/anime-whisper --mlx-path ~/models/anime-whisper-mlx --dtype float16
mv ~/models/anime-whisper-mlx/model.safetensors ~/models/anime-whisper-mlx/weights.safetensors
  4. Start the translator and leave it running: 
    llama-server -m ~/models/<model>.gguf --port 9931 -ngl 99 -c 16384 --jinja --reasoning-budget 0
    Or fill in Settings → llama-server auto-start: the app starts it when needed and stops it on Shut down server.
  5. Settings: Backend mlx-whisper; executable ~/mlx-whisper-env/bin/mlx_whisper; --model: choose anime-whisper (this turns VAD segmentation on and clears the initial prompt).
  6. Settings → Translation: Two-stage, click llama.cpp (local) (127.0.0.1:9931), leave key and model blank.
  7. Set the watch folder (below this panel), then Start. Each video gets video.srt (or .ja.srt + .en.srt with Keep only English subtitles unticked); 📂 opens its folder; EN↻ re-translates from a kept .ja.srt. A chime plays when the queue is done.

Keep --initial-prompt blank with anime-whisper: its author says prompts make it hallucinate.

Alternative model: whisper-ja-1.5B (similar accuracy, about 3 GB, slower). Convert it the same way with --torch-name-or-path efwkjn/whisper-ja-1.5B --mlx-path ~/models/whisper-ja-1.5B-mlx, then pick it in the dropdown.

PC (NVIDIA CUDA): whisper-ctranslate2 + local llama-server

  1. Install Node 18+, Python 3, and ffmpeg (winget install Gyan.FFmpeg), then: 
    pip install -U whisper-ctranslate2 "ctranslate2>=4.8.1" "av<16"
    (newer PyAV versions crash faster-whisper 1.2.1 while decoding audio).
  2. Keep the CUDA 12.x runtime + cuDNN 9 libraries. CTranslate2 doesn't load on CUDA 13 yet (libcublas.so.12 not found).
  3. Get anime-whisper in CTranslate2 format (one time): 
    pip install transformers torch
ct2-transformers-converter --model litagin/anime-whisper --output_dir ~/models/anime-whisper-ct2 --copy_files preprocessor_config.json --quantization float16
hf download openai/whisper-large-v3 tokenizer.json --local-dir ~/models/anime-whisper-ct2
    The tokenizer.json step is required: without it faster-whisper uses the wrong tokenizer and outputs gibberish.
  4. Settings: Backend whisper-ctranslate2; --device cuda; --compute_type int8_float16 (float16 garbles output on RTX 50-series; not float32); --model: choose anime-whisper (turns VAD segmentation on, clears the initial prompt).
  5. Install llama.cpp (winget install llama.cpp); llama-server --list-devices must show the GPU, otherwise use a CUDA build from llama.cpp's GitHub releases. Get an instruction-tuned ~27B .gguf (Qwen or Gemma, Q4–Q6).
  6. Settings → Translation: Two-stage, click llama.cpp (local), then under llama-server auto-start set the executable (e.g. C:\llama-cuda\llama-server.exe) and pick the model. Save & test translation starts it and translates a sample line; the app starts and stops llama-server from then on. (Cloud alternative: click OpenRouter, paste your API key and a model id.)
  7. Set the watch folder (below this panel), then Start. Outputs and EN↻ work the same as on the Mac.

Keep --initial-prompt blank with anime-whisper: its author says prompts make it hallucinate. It also needs VAD segmentation on: it has no timestamps, and the plain CLI crashes on it.

Alternative models (pick them in the --model dropdown): whisper-ja-1.5B (similar accuracy, about 3 GB, slower), already converted: hf download TransWithAI/whisper-ja-1.5B-ct2 --local-dir ~/models/whisper-ja-1.5B-ct2; whisper-ja-anime-v0.3 (experimental): ct2-transformers-converter --model efwkjn/whisper-ja-anime-v0.3 --output_dir ~/models/whisper-ja-anime-v0.3-ct2 --copy_files tokenizer.json preprocessor_config.json --quantization float16; kotoba-whisper v2.0 (fast): hf download kotoba-tech/kotoba-whisper-v2.0-faster --local-dir ~/models/kotoba-whisper-v2.0-faster (v2.1 and v2.2 are the same model plus punctuation/speaker steps that only run in Hugging Face's own pipeline).

Mac (Apple Silicon)

  1. Install ffmpeg: 
    brew install ffmpeg
  2. Browse to a folder on the left (its subfolders are listed with their videos; click a folder to open it, .. goes up) and tick the videos in playback order.
  3. Reorder on the right with ▲ ▼, and remove with ✕.
  4. Edit the output name if you like (defaults to a+b.mp4), then Concat.

The output is saved next to the first selected file. If it's inside the watch folder, it's added to the Translate queue automatically.

PC (NVIDIA CUDA)

  1. Install ffmpeg and make sure ffmpeg / ffprobe are on PATH: 
    winget install Gyan.FFmpeg
  2. Same steps as on the Mac: pick files in order, reorder, name, Concat.

Concat uses stream copy (no re-encode), so it's near-instant and uses no GPU on either machine. All parts must share codec, resolution and frame rate (e.g. pieces of one download). Cancel deletes the partial file.

Installing a model on the PC

Stock names (large-v3, large-v2…) download by themselves. Anything else must be a CTranslate2 folder saved under ~/models/<name> (C:\Users\<you>\models\<name>). Choose Custom and enter that folder.

Already CTranslate2 on Hugging Face (names ending -ct2 / -faster):
hf download <repo> --local-dir ~/models/<name>

A regular (Transformers) whisper model:
ct2-transformers-converter --model <repo> --output_dir ~/models/<name> --copy_files preprocessor_config.json --quantization float16

The folder must contain tokenizer.json. If it doesn't, copy the one from openai/whisper-large-v3 (for large-v3-based models such as anime-whisper); without it the output is gibberish.

Models without timestamps (anime-whisper) need VAD segmentation = True. Qwen3-ASR is not a whisper model and won't work here.

Installing a model on the Mac

Hugging Face repos already in MLX format (e.g. mlx-community/whisper-large-v3-mlx) download by themselves to ~/.cache/huggingface.

Any other whisper model: convert it into ~/models/<name> with mlx-examples' whisper/convert.py (run with the mlx venv's python):
python convert.py --torch-name-or-path <repo> --mlx-path ~/models/<name> --dtype float16
then rename model.safetensors to weights.safetensors. Choose Custom and enter the folder.

Models without timestamps (anime-whisper) need VAD segmentation = True. Qwen3-ASR is not a whisper model and won't work here.

Mode
Two-stage writes video.ja.srt and video.en.srt (just video.srt with Keep only English, below) and always runs whisper with --task transcribe. Single-stage writes video.srt as before.
Keep only English subtitles
Leaves one subtitle file next to each video, named so players load it automatically (an existing video.srt is replaced). If translation fails or is stopped, the .ja.srt is kept so a retry skips transcription. Deleted transcripts can't be re-translated with EN↻; untick this to keep .ja.srt and .en.srt for comparing models.
